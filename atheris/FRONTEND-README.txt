ATHERIS CARE FRONTEND

This PHP website is connected to the Flask API in the sibling ../backend folder.
See the project-root README.md and START_HERE.txt for the two-terminal startup steps.

The API URL is configured in js/atheris-api-config.js. The local default is
http://127.0.0.1:5000/api.

This is a public shared demonstration. Use fictional data only; never enter real or sensitive
medical information. No login or registration is required.
